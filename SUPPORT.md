# Support

Before opening an issue:

1. Check `docs/installation.md` and `docs/supported-hardware.md`.
2. Run the documented health checks and include redacted output.
3. Include OS version, deployment mode (native/container), coordinator model, adapter type, Zigbee2MQTT version, and relevant logs.
4. Remove passwords, MQTT credentials, network keys, device identifiers, IP addresses, and other private information from logs.

Please use GitHub issues for reproducible bugs and feature requests. This project is community-supported and has no guaranteed response time.
